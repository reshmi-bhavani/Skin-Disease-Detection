# Skin Disease Detection

# Overview

Skin Disease Detection is a web-based machine learning project that classifies skin-condition images using the **Nyckel Machine Learning API**. Users can upload or drag and drop an image, and the system processes the image and returns the predicted skin condition.

The project uses a lightweight frontend architecture with **HTML, CSS, JavaScript, and jQuery**, without a traditional backend or database.

# Features

* Skin disease prediction from uploaded images
* Image upload and drag-and-drop functionality
* Live image preview
* Image processing using JavaScript
* Image classification using Nyckel ML API
* Instant prediction display
* Responsive and user-friendly interface
* No traditional backend or database required

# Tech Stack

* HTML5
* CSS3
* JavaScript
* jQuery 3.6.0
* Nyckel Machine Learning API

# Supported Conditions

* Acne
* Melanoma
* Vitiligo
* Shingles

# Workflow

1. User uploads or drags and drops a skin-condition image.
2. JavaScript validates and processes the image.
3. The processed image is sent to the Nyckel ML API.
4. Nyckel analyzes the image using the trained classification model.
5. The predicted skin condition is returned.
6. The prediction is displayed on the webpage.
